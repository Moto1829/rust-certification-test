# App Implementation

## 目的
選択式クイズをブラウザで実行できるUIとロジックを実装する。

## Tasks
- [x] クイズ開始前に難易度（`beginner` / `intermediate` / `advanced`）を選択/フィルタできるUIを実装する
- [x] クイズ開始前に出題数（5/10/30/50/100）を選択できるUIを実装する
- [x] 難易度フィルタ条件に合う問題のみを出題対象にする
- [x] フィルタ結果が出題数に満たない場合の挙動を実装する（警告表示または出題数再選択）
- [x] 問題を1問ずつ表示するUIを実装する
- [x] 選択肢クリック時に回答判定を行う
- [x] 正誤結果と解説を表示する
- [x] 出典リンクを問題ごとに表示する
- [x] 次の問題へ進む操作を実装する
- [x] スコア（正答数/総問題数）を表示する
- [x] 終了後に正答率（%）を表示する
- [x] 最終結果画面を実装する
- [x] 終了後に全回答の振り返り（問題・自分の回答・正答・解説）を表示する
