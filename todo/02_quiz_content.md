# Quiz Content

## 目的
Rust公式ドキュメント（日本語版）を出典とした問題セットを作成する。

## Tasks
- [x] 出題範囲を章単位で定義する（優先章を決める）
- [x] 各問題のデータ形式を定義する（問題文、選択肢、正答、解説、出典URL、難易度）
- [x] 問題データのJSON Schemaを作成する（`question/quiz.schema.json`）
- [x] 問題データは「1問1ファイル（`question/items/<id>.json`）」で管理する
- [x] 問題ファイルの命名規則とID規則を定義する（例: `topic_name_001`）
- [x] 問題一覧インデックス（`question/index.json`）を作成・更新する運用を定義する
- [x] `question/items` から `question/index.json` を自動生成する
- [x] 問題データのバリデーションコマンド（`npm run validate:questions`）を整備する
- [x] 最低100問分の問題セットを用意する（5/10/30/50/100問出題に対応、現在100問）
- [x] 各問題に出典リンクを必ず付与する
- [x] 解説が必要な問題に補足説明を記述する
- [x] 難易度は `beginner` / `intermediate` / `advanced` の3段階で定義する
- [x] 難易度付与ルールを定義する（章の難度、必要前提知識、ひっかけ要素の有無）
- [x] 振り返り表示用の項目（設問ID、ユーザ回答、正誤）を保持できる形式を定義する
- [x] 問題品質チェック基準を作る（正確性・曖昧性・難易度）
- [x] 問題品質レポート（`npm run report:questions`）を生成できるようにする
