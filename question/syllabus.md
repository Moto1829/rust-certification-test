# Question Syllabus

出題範囲を章単位で整理したシラバスです。問題追加時はこの表の章とタグを紐づけて作成します。

## rust-jp book（優先）
- Ch03: 変数・データ型・制御構文（beginner）
- Ch04: 所有権・借用・スライス（beginner〜intermediate）
- Ch05: 構造体（beginner〜intermediate）
- Ch06: enum / match / if let（beginner〜intermediate）
- Ch07: モジュールと可視性（intermediate）
- Ch08: コレクション/文字列（beginner〜intermediate）
- Ch09: Resultによるエラー処理（beginner〜advanced）
- Ch10: ジェネリクス/トレイト/ライフタイム（intermediate〜advanced）
- Ch13: クロージャ/イテレータ（intermediate〜advanced）
- Ch15: Smart Pointer / Drop / Rc（intermediate〜advanced）
- Ch16: 並行性（channels, Mutex, Send/Sync）（advanced）
- Ch18: パターン（intermediate〜advanced）
- Ch19: unsafe Rust / FFI（advanced）

## async-book
- Getting Started（beginner）
- async/await primer（beginner〜intermediate）
- Multiple futures / join（intermediate〜advanced）
- Pin / runtime model（advanced）

## Effective Rust
- API設計・エラーメッセージ設計（intermediate）
- 安全な抽象化とunsafe境界（advanced）
- 実務向けベストプラクティス（intermediate〜advanced）

## 運用ルール
- 新規問題は必ず上記章に紐づくタグを1つ以上付与する。
- 難易度は `question/difficulty-guidelines.md` を基準に決定する。
- 重点強化領域（不足領域）は `reports/question-report.md` の Recommendations を参照する。
